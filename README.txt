HOW TO USE (3 steps)

1. Right-click the zip file -> Extract All.
2. Open the extracted folder and double-click  START_HERE.bat
   (A black window opens. Keep it open.)
3. Your browser opens the detector page automatically.
   If it does not, open Chrome or Edge and go to:  http://localhost:8000

In the page:
 - Webcam tab  -> click "Start webcam" and allow the camera
 - Video tab   -> choose a video file
 - Image tab   -> choose an image
 - Save snapshot / Record video / Download result -> download the output

You need internet the first time (the model downloads).
To stop: close the black window.

Ignore the folder "optional-python-version". It is not needed.
